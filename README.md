## Projeto em destaque

Produto operacional criado para centralizar análises, tratativas, auditorias e automações em uma única experiência.

**Impacto público**

- 13 fluxos automatizados

O portfólio inclui uma demonstração local com dados sintéticos. Nenhuma credencial, URL interna, endpoint corporativo ou dado real de operação é publicado neste repositório.

## Executar localmente

O projeto é estático. Abra `index.html` diretamente no navegador ou use um servidor HTTP local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Privacidade e segurança

- As demonstrações usam somente dados fictícios gerados no navegador.
- O campo de consulta não envia o valor digitado a terceiros.
- O Google Analytics permanece desativado enquanto não houver um ID GA4 válido em `analytics.js`.
- Mesmo quando ativada, a análise só é carregada após consentimento explícito do visitante.
