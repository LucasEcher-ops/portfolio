# Portfólio — Lucas Echer

Portfólio profissional dedicado a projetos de automação, melhoria de processos e soluções operacionais.

## Projeto em destaque

### Problem Solver Bot

Case criado para reduzir etapas repetitivas, organizar consultas e tornar rotinas operacionais mais consistentes.

A apresentação pública prioriza o problema resolvido, as decisões de produto, a arquitetura em alto nível e as competências demonstradas. Credenciais, URLs internas, dados operacionais e código de produção não fazem parte deste repositório.

## Impacto

- Mais de 150 usuários
- Mais de 10 mil tratativas realizadas
- 7 fluxos automatizados
- 8 setores impactados
- 3 galpões atendidos
